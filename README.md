# NutriTrack - Vanilla Calorie & Macro Tracker

NutriTrack is a lightweight, responsive daily calorie and macronutrient tracker built with 100% vanilla web technologies.

## Features
- **Daily Calorie Dashboard**: Real-time progress ring tracking calories consumed vs. goal vs. remaining.
- **Macro Tracking**: Track Protein, Carbs, and Fats against customized gram goals with energy distribution ratios.
- **Meal Logs**: Breakfast, Lunch, Dinner, and Snacks categorization with inline item editing and deletion.
- **Food Library & Presets**: 30+ built-in common healthy staples and ability to save custom foods.
- **TDEE & Calorie Goal Calculator**: Mifflin-St Jeor scientific formula to estimate BMR, TDEE, and automatically configure nutrition goals.
- **7-Day Trend Chart**: SVG history chart comparing intake against daily budget.
- **Water Intake Tracker**: 8-glass water counter (250 ml/glass) and streak counter.
- **Zero Backend / Complete Privacy**: All data is stored in the browser's `localStorage` with JSON export/import support.
- **Zero Frameworks**: No Tailwind, no CSS variables, pure vanilla HTML/CSS/JS.

## How to Run
Open `index.html` directly in any web browser. No server, install, or build step required.
